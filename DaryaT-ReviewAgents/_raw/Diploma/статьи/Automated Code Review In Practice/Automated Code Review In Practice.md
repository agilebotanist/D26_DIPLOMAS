## Суть работы
Авторы изучают, как внедрение ИИ-ревью на основе Qodo PR-Agent влияет на работу разработчиков. Они анализируют 4 335 PR в трёх проектах Beko и дополняют эти данные опросами разработчиков.

73,8% из 1 408 проанализированных ИИ-комментариев получили от авторов PR статус `Resolved` — рекомендация реализована. В общем опросе 14 из 22 участников отметили небольшое улучшение качества кода.

В открытых ответах разработчики отмечали раннее обнаружение дефектов, поддержку стандартов и повышение внимания к качеству. Среди недостатков они называли ошибочные и выходящие за рамки PR рекомендации, избыточные комментарии при повторных ревью и пропуск проблем, которые мог бы заметить человек.

При этом среднее время закрытия PR выросло с 5 ч 52 мин до 8 ч 20 мин, хотя результаты различались между проектами. Число человеческих комментариев на PR статистически значимо не изменилось. Авторы не нашли убедительных свидетельств устойчивой экономии времени или усилий: работа с замечаниями ИИ не устранила потребность в человеческом ревью.

Авторы оговаривают ограничения исследования: результаты получены для одного инструмента в одной компании, а статусы `Resolved` могли выставляться неточно. Поэтому долю таких статусов нельзя считать независимо проверенной долей реализованных рекомендаций.
