## Суть концепции

Авторы сравнили работу агентов с **автоматически сгенерированными LLM файлами контекста** (`AGENTS.md` или `CLAUDE.md`) и без таких файлов. Для генерации использовали рекомендованную команду инициализации и модель каждого агента.

Проверили четыре сочетания агента и модели: Claude Code с Sonnet 4.5, Codex с GPT-5.2, Codex с GPT-5.1 Mini и Qwen Code с Qwen3-30B-Coder. Каждое проверяли на двух бенчмарках — SWE-bench Lite и CTXBench, поэтому всего получилось восемь сочетаний.

Статистически значимого изменения доли решённых задач не обнаружили. При этом число шагов агента выросло во всех восьми сочетаниях. Средняя стоимость выполнения задач увеличилась на 20% на SWE-bench Lite и на 23% на CTXBench; этот рост был статистически значимым.

Этот результат относится к автоматически сгенерированным файлам в исследованных условиях. Файлы контекста, предоставленные разработчиками, авторы оценивали отдельно.
