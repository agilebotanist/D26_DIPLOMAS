## Суть концепции

В эксперименте обычный и пошаговый чек-листы получили близкие средние оценки по адаптированной System Usability Scale (SUS): 57,35 и 58,5 соответственно. По использованной авторами интерпретации обе оценки соответствуют D — Poor usability, низкому удобству использования.

Авторы предполагают, что неудобная реализация не была главной причиной низкой результативности ревью: контрольная группа без чек-листов показывала ещё более низкие результаты.

## Мои мысли

Для меня этот результат показывает, что пошаговая подача чеклиста сама по себе не гарантирует удобства его использования. В дипломе я сравниваю способы выполнения проверок агентом, поэтому оценки удобства для людей не позволяют выбрать между этими способами.
