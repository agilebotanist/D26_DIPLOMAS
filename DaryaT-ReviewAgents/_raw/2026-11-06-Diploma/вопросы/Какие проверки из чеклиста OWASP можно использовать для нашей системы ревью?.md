## Суть вопроса

Какие проверки из чеклиста OWASP могут пригодиться для нашей системы ревью и как их адаптировать под конкретный проект или изменение?

Источник: [[Less is More Supporting Developers in Vulnerability Detection during Code Review]], §3.3, с. 5–6 PDF; ссылка [63]. Авторы использовали OWASP Code Review Guide 2.0 (2017): на основе исходного чеклиста из 78 пунктов вручную подготовили варианты из 22 и 7 пунктов.

Хоть это и относится к security проверкам, все равно хочется посмотреть пример популярного чеклиста, чтобы иметь большее представление о чеклистах в целом.

## Идеи

- Посмотреть [Code Review Checklist в OWASP Code Review Guide v2](https://owasp.org/www-project-code-review-guide/assets/OWASP_Code_Review_Guide_v2.pdf#page=197). Раздел находится в приложении: печатные с. 196–199, с. 197–200 PDF.
- Сравнить исходный чеклист с двумя адаптированными вариантами из [материалов Less is More](https://zenodo.org/records/6026291). Устройство эксперимента сохранено в [[Пример эксперимента с инструкциями и чеклистами из Less is More]].
- Сопоставить проверки и рекомендации с другими материалами для изучения: [[Какие чеклисты Microsoft из Code Complete можно использовать для нашей системы ревью?]], [[Как устроено код-ревью в Google?]].

## Статус

- [ ] Изучить чеклист и выписать проверки, подходящие для нашей системы.
