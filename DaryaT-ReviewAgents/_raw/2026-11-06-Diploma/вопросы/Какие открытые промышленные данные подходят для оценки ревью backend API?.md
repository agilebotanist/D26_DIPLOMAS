## Суть вопроса

Есть ли открытые наборы данных ревью от крупных компаний, которые можно использовать для оценки изменений реализации, тестов и документации backend API?

Вопрос предложил Данила на коллоквиуме 26 октября 2026 года. Он относится к подготовке оценки системы: [[Источники данных и ограничения оценки]].

## Идеи

При изучении кандидатов важно различать описание промышленного исследования и фактическую публикацию его данных. Для каждого кандидата можно выяснить:

- доступны ли сами данные и разрешено ли их использование;
- есть ли изменения backend API, а не только отдельные функции или примеры по безопасности;
- сохраняются ли репозиторий, исходный коммит, описание задачи и diff;
- есть ли подтверждения известных проблем и подходящие примеры без целевой проблемы;
- доступны ли материалы для оценки реализации, тестов и документации.

Уже рассмотренные примеры дают отправные точки:

- [[Пример датасета для оценки ревью в iCodeReviewer]] — внутренние данные компании; в заметке отмечено отсутствие ссылки на публикацию набора.
- [[Пример датасета SWE-Review-Bench]] — открытый набор с репозиториями и патчами; сам по себе не отвечает на вопрос о данных от крупных компаний.
- [[AI-Assisted Assessment of Coding Practices in Modern Code Review]] и [[RovoDev Code Reviewer A Large-Scale Online Evaluation of LLM-based Code Review Automation at Atlassian]] — промышленные исследования, для которых доступность подходящих данных нужно проверять отдельно.

## Статус

**В разборе.** Проведён первичный поиск публичных наборов, включая релизы Microsoft, Alibaba, Ant Group и GitHub. Сравнение и ограничения собраны в [[Открытые датасеты для оценки ИИ-ревью]]. Итоговый набор и объём подходящих backend API-примеров пока не определены.
