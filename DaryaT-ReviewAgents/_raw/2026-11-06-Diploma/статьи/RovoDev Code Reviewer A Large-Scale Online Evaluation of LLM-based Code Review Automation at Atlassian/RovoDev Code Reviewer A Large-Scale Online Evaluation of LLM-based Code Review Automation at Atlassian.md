## Суть работы

RovoDev — система ИИ-ревью Atlassian, которая учитывает контекст и правила ревью, затем проверяет корректность и применимость замечаний. Авторы оценивают её годовое внедрение в более чем 1900 репозиториях по изменениям кода после замечаний, времени PR, числу человеческих комментариев и отзывам разработчиков.
