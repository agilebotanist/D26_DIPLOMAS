## Суть работы

Авторы предлагают диалогового LLM-помощника для код-ревью, который отбирает и объясняет контекст и результаты инструментов анализа с учётом изменения и опыта ревьюера. Работа описывает концепцию и открытые исследовательские вопросы.

## Выделенные идеи и заметки

- [[Агент может формировать чеклист ревью из истории и правил проекта]]
- [[Помощь ревьюеру можно адаптировать к его знакомству с кодом]]
- [[При отборе информации для ревью нужно учитывать полезность и полноту]]
