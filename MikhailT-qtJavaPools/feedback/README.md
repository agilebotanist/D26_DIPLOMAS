# feedback/

Reviews and supervisor feedback on this student's drafts.

```
feedback/
├── reviews/         # output of the reviewers skill
│                    # <target>-<mode>-<profile>-<YYYY-MM-DD>.md
├── call-context/    # per-venue criteria when targeting a submission
└── <free notes>     # supervisor comments on a draft
```

Generated by `/review`, which reads `.claude/skills/reviewers/`.

This repo is private to the supervisor. Notes here may be candid in a way that is not meant
to reach the student verbatim. What goes to the student is the meeting note and the action
list.
