# Microsoft now has more than 20M paying Copilot users

**URL:** https://www.computerworld.com/article/4166676/microsoft-now-has-over-20-million-paying-copilot-users.html
**Description:** According to CEO Satya Nadella, the AI assistant is used just as much as Outlook.
**Scraped:** 2026-11-17T15:10:47.421969+00:00

---

![Microsoft Copilot](https://www.computerworld.com/wp-content/uploads/2026/05/4166676-0-86082100-1777989960-0-microsoft-copilot-100946694-orig.jpg?quality=50&strip=all)

Microsoft Copilot

Microsoft CEO Satya Nadella last week announced that the company now has more than 20 million enterprise users paying for Microsoft Copilot, [according to TechCrunch](https://techcrunch.com/2026/04/29/microsoft-says-it-has-over-20m-paid-copilot-users-and-they-really-are-using-it/). That’s up 33% from the [15 million paying customers Microsoft claimed in January](https://www.computerworld.com/article/4124591/microsoft-touts-m365-copilot-momentum-claims-15m-paid-users.html).

The AI assistant is now directly integrated in programs such as Word, Excel, and Outlook and Microsoft is [rolling out new agent features](https://www.computerworld.com/article/4158553/microsoft-is-developing-copilot-features-inspired-by-openclaw.html) that allow Copilot to perform multiple steps automatically directly within documents and presentations.

According to Nadella, the number of questions asked of Copilot per user rose by nearly 20% compared to the previous quarter. Weekly usage is now reportedly on par with the Outlook email service.

Microsoft says one advantage for Copilot is that it is no longer locked to a single provider of AI models. In addition to OpenAI’s GPT models, it now also supports models such as Anthropic’s Claude.
