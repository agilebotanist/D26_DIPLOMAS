**Amazon Q Developer** transformed **30,000** internal applications from **Java 8** or **11** to **Java 17**, saving an estimated **4,500 developer-years** of work and generating **$260 million** in annual savings from performance improvements.

In **February 2025**, AWS expanded these capabilities to support upgrades to **Java 21**, offering enhanced performance, security, and features like Sequenced Collections and improved memory management.

Key updates include:

- **Java 21 Support**: Upgrades from source versions 8, 11, 17, or 21 to target versions 17 or 21 are now available in both IDEs and the Command Line Interface (CLI).
- **Selective Transformation**: A feature allowing developers to customize transformation plans, selecting specific steps and dependencies to upgrade for greater control and stability.
- **CLI General Availability**: The Java upgrade transformation CLI became generally available in **June 2025**, enabling scalable, command-line-based modernization on Linux and macOS.
- **Efficiency**: The tool reduces upgrade time from weeks or days to minutes, with internal reports indicating that **79%** of auto-generated code reviews were applied without additional changes.
