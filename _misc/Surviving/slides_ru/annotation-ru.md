# Выживание в эру агентов

**Андрей Садовых, Университет Иннополис**

ИИ-агенты сделали написание кода дешёвым, но проверка, выбор цели и ответственность за результат дешевле не стали. В докладе на данных 2025–2026 годов разбираем, что это значит для ИТ-компаний, для специалистов и для студентов: куда уходят деньги, кого перестают нанимать и какие роли остаются востребованными. Для каждой группы — гид по выживанию, а в конце — задачи, ради которых эти навыки стоит развивать.
