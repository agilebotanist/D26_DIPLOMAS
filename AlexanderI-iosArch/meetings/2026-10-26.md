**Итог:** Работа интересная, подход валиден, измерительная часть проработана. Не хватает литературы о том, кто решал похожие задачи с агентами, и строгого definition of done для задач агента.

## Почему

- Измерение обосновано — граф зависимостей, propagation cost, instability, четыре архитектурных запаха; профиль из четырёх аспектов; свой анализатор на SwiftSyntax.
- Позиционирования нет — в презентации нет списка литературы и раздела «кто решал похожее»: агенты и архитектура, рефакторинг с ИИ. Тезис «исследования показывают, что агенты так ошибаются» без ссылки.
- Definition of done слабый — сборка, тесты и ручные smoke-проверки; в iOS-проектах мало тестов, regression-тесты рефакторинг не ловят.
- Данные не ограничены — размер задачи не измерен, решение закрытой issue агент может найти в интернете, порог 30K LOC из личного опыта.
