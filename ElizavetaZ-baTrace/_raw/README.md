# _raw/

Whatever the student sent, exactly as sent. Documents, PDFs, reading logs, pasted messages.

Nothing here is edited and nothing here is authoritative. This is intake.

What matters gets read out into the right place: references into `lit/references.bib` and
`lit/status.md`, thesis text into `work/`, facts about the student into `PROFILE.md`,
commitments into `ACTIONS.md`. The raw file then stays as provenance.

A file here that has not been read out is unprocessed work.
